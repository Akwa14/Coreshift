# Coreshift
"Coreshift" - фоновая утилита для Windows, которая автоматически снижает приоритет и нагрузку фоновых программ (Discord, Chrome, Telegram) при запуске игр и тяжелых приложений, а после их закрытия возвращает все как было. Поддерживает пользовательские конфиги. Python.

| № | Блок | Папка |
|---|------|-------|
| 1 | Process Monitor | process_monitor |
| 2 | Process Classifier | process_classifier |
| 3 | Resource Manager | resource_manager |
| 4 | Config Manager | config_manager |
| 5 | State Manager | state_manager |
| 6 | Background Service | background_service |
| 7 | UI / Tray Icon | ui_tray |
| 8 | Logger | app_logger |
